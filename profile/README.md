# FEM-Design — building analysis with RC load cases

FEM-Design keeps one named board on the desk: the live building model, the load case in front of you, and a short note the next engineer can read. Extra structures wait for their own title.

## Session Card

| Slice | What you do in FEM-Design | What remains |
|-------|------------------------|--------------|
| Arrival | Open FEM-Design and name today's structural desk | A titled building model |
| Focus | Keep only live load cases on the FEM-Design board | A short RC list |
| Check | Read FEM-Design RC design before a large load change | A confirmed structural desk |
| Handoff | Mark finished load cases inside FEM-Design | A note for the next engineer |
| Hold | Leave the structure title on the FEM-Design model | A named load case set |

## How FEM-Design Sits

FEM-Design does not replace the unlabeled building dump, the separate RC spreadsheet, or the second analysis seat you already keep. It sits beside them as a named structural desk for one job: which building analysis is live, which RC design still matches the load cases, and what the next engineer should read.

If two people share a structure PC, each keeps a FEM-Design style of their own. Extra buildings wait for their own title instead of crowding the live load cases.

A first visit should be one short RC pass, then the same FEM-Design structural desk the next day. That is enough to see if the named building model holds.

## Traffic Light

| Signal | On the FEM-Design board | What you do |
|--------|----------------------|-------------|
| Green | Named building model, short live load list | Continue the same building analysis |
| Amber | Two structures mixed on one RC design | Split the load cases before a large change |
| Red | No title, no note, RC on a second sketch | Stop and name the structural desk first |
| Clear | Handoff written, live load cases few | Close FEM-Design and leave the structural desk |
| Hold | Load cases written, RC still open | Finish the check, then close |

## Open Order

1. Open the last FEM-Design structural desk, not a new empty building model.
2. Read the load cases and the last handoff.
3. Finish one visible RC design pass inside FEM-Design.
4. Write what changed, then close with fewer unlabeled buildings than you found.
5. If the model feels crowded, drop anything that belongs to a different FEM-Design structure.
6. Confirm FEM-Design building analysis still sits on the named building model.
7. Leave the structural desk title on the board before you close.

## After a Week

A week in FEM-Design is not a larger unlabeled building pile. It is the same title, a shorter live load list, and a note that still makes sense before the next RC check. Take finished load cases off the live set so the next visit starts on the structural desk that is still open.

Other programs stay where they are. FEM-Design only keeps the path back: desk name, building analysis, load cases, handoff.

Leave FEM-Design with a quieter structural desk than the one you opened. The next visit should start on that named building model, not in a search.

## Sign-off

- [ ] The FEM-Design workspace name is short enough to scan
- [ ] Only live load cases sit on the building analysis
- [ ] A second engineer can read the RC handoff
- [ ] The last FEM-Design building model still opens after a restart
- [ ] Finished load cases are off the live FEM-Design set
- [ ] The FEM-Design summary still matches the RC design on the board

## Field Note

FEM-Design is easier to trust when the structural desk stays smaller than the unlabeled building dump it came from. Name the building model, keep the live load cases, finish one visible RC pass, and write what changed.

The same loop fits an office review, a close-out, or a shared structure PC. Open the last FEM-Design desk and continue. Do not rebuild the load case set from scratch.

A named building model is enough. Do not pin every structure you keep onto the live RC design.
